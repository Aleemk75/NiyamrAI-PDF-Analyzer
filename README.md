NiyamrAI – PDF Rule Checker
A lightweight AI-powered PDF auditing tool built with Node.js, Express, EJS, Multer, pdf-parse, and Gemini 2.5 Flash.
Users can upload a PDF, enter simple rules, and instantly get PASS/FAIL results with evidence, reasoning, and confidence — all generated by an LLM.


✨ Features
✅ PDF Upload – Upload 2–10 page PDF documents for analysis
✅ Rule-Based Checks – Enter any 3 rules in plain English
✅ LLM Evaluation – Each rule is checked using Gemini 2.5 Flash
✅ Pass/Fail Output – Determines if the PDF satisfies the rule
✅ Evidence Sentence – Extracted from PDF for proof
✅ Reasoning – Short explanation generated by AI
✅ Confidence Score – Percentage (0–100) for each evaluation
✅ Clean UI – EJS frontend with Home & Result screens
✅ PDF Text Extraction – Uses pdf-parse
✅ Fast & Lightweight – No database required

🧠 How It Works


User uploads a PDF


App extracts text using pdf-parse


Sends text + rules to Gemini 2.5 Flash


Model analyzes each rule and returns:


pass/fail


evidence


reasoning


confidence score




Results rendered on result.ejs



🏗️ Tech Stack


Backend: Node.js + Express.js


Templating: EJS


File Uploads: Multer


PDF Parsing: pdf-parse


AI Model: Gemini 2.5 Flash


UI: EJS + basic CSS


Environment: dotenv


Dev Tools: nodemon



📋 API Endpoint
Analyze PDF
POST /api/check/analyze
Content-Type: multipart/form-data

Form Data Fields:


pdf – Uploaded PDF file


rule1 – Text


rule2 – Text


rule3 – Text


Response:
[
  {
    "rule": "Document must mention a date.",
    "status": "pass",
    "evidence": "Found on page 1: 'Published 2024'",
    "reasoning": "A valid date reference is present.",
    "confidence": 92
  }
]


🚀 Installation & Setup
1. Clone the Repository
git clone https://github.com/your-username/niyamrai-docaudit.git
cd niyamrai-docaudit

2. Install Dependencies
npm install

3. Environment Variables
Create .env:
PORT=3000
GEMINI_API_KEY=your_api_key_here

4. Run the Application
npm run dev

App starts at:
👉 http://localhost:3000
